# Asset Versioning

## Purpose
Defines how significant asset changes should be tracked.

## Rule
Asset changes that affect implementation or visual intent should be traceable through Git history and relevant documentation revisions.

## Reference Images
When replacing a reference image, update the Reference Manifest in the same change.
