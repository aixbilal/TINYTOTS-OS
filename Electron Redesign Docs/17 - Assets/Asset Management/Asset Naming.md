# Asset Naming

## Purpose
Defines stable asset naming conventions.

## Recommended Convention
Use descriptive, stable names that communicate asset purpose.

Avoid opaque UUID-only filenames for canonical documentation assets.

## Current Package
The user's current filenames are preserved exactly for traceability. They can be normalized later as a controlled change, with the manifest updated simultaneously.
