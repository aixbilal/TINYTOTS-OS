## Purpose

Phase 17 defines the asset and visual-reference layer of the TinyTots OS Electron POS engineering repository.

It documents:

- visual reference material
- brand assets
- icons
- images
- illustrations
- business-specific visual assets
- generated references
- asset naming and management rules

Phase 17 does not redefine the design system, screen behavior, component behavior, or application architecture.

## Source Discipline

The redesign specification remains the primary source for intended future-state design requirements.

The verified repository remains the source for current implementation.

The reference-image package is supporting visual evidence for layout, composition, hierarchy, and recurring visual patterns.
