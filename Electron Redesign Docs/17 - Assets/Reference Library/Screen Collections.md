# Screen Collections

## Purpose

Documents the screen-collection sheets as grouped visual references.

## Complete Screen Library

The master library visibly groups the application into a cohesive desktop POS ecosystem, including authentication, dashboard, POS, inventory, products, categories, barcode generation, receipts, performance, customers, reports, settings, and administrative/system states.

## Core Screen Library — Sheet 1

The first core sheet groups dashboard, POS, inventory, product detail, add/edit product, categories, barcode generation, receipts, receipt details, performance, goals, customers, reports, and settings.

## Core Screen Library — Sheet 2

The second core sheet groups user management, profile, notifications, activity logs, printer settings, store settings, backup/restore, import/export, empty states, error states, loading states, success states, and confirmation dialogs.
