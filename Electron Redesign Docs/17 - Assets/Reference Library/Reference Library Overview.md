# Reference Library Overview

## Purpose

Defines the role of the visual-reference library within the Electron POS documentation.

## Contents

The current reference package contains seven visual reference sheets:

1. Complete Screen Library
2. Core Screen Library — Sheet 1
3. Core Screen Library — Sheet 2
4. Dashboard Screen Reference
5. Inventory Screen References
6. Dashboard State/Phase References
7. POS Screen References

## Usage

Use these images to validate:

- composition
- hierarchy
- screen relationships
- recurring UI patterns
- visual state representation

Do not use reference images alone to infer backend behavior, data contracts, permissions, or implementation details.
