## Source Discipline

The redesign specification is the primary source for target-state requirements. The verified repository is used to establish current implementation. Engineering inference must not be presented as fact; unsupported information remains TODO.

## Architectural Preservation

Feature documentation does not silently redesign Phase 03 architecture. Any required architectural change must be explicitly identified as a proposed change or TODO.
