# Assets

> Version: 1.0

---

# Purpose

The Assets directory contains all non-code resources used throughout the TinyTots WhatsApp project.

Unlike the documentation folders, this directory stores project artifacts that are created during design, development, testing, and deployment.

This includes architecture diagrams, exported workflows, screenshots, JSON examples, Postman collections, presentations, prompts, and other supporting resources.

# Rules

- Prefer editable source files over exported files.
- Never manually edit exported workflow JSON.
- Keep screenshots organized.
- Archive outdated assets instead of deleting them.
- Update diagrams whenever the architecture changes.
- Version important assets before making breaking changes.
