# Incident Response

---

# Purpose

Defines the response process for production incidents.

---

# Severity Levels

Critical

Platform unavailable.

High

Core functionality unavailable.

Medium

Feature degradation.

Low

Minor issue.

# Communication

Inform:

- Development Team
- Administrators
- Business Stakeholders

If customer impact is significant, prepare a customer communication plan.
