# Monitoring

---

# Purpose

Defines what should be monitored after deployment.

---

# Monitor

- Website uptime
- API response time
- Supabase health
- n8n executions
- WhatsApp delivery
- Business Agent availability

---

# Key Metrics

- API latency
- Workflow failures
- Message delivery success
- Error rate
- Retry count

---

# Alerts

Notify administrators when:

- APIs become unavailable
- Workflow failures exceed threshold
- Message delivery fails repeatedly
- Database connection is lost
