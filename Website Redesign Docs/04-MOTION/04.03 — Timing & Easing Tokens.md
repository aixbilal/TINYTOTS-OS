# TinyTots Motion Timing & Easing Tokens

## 1. Semantic Durations

Use semantic names rather than arbitrary milliseconds:

```text
motion.instant
motion.fast
motion.standard
motion.slow
motion.cinematic
```

Exact values must be finalized during implementation testing.

## 2. Functional Motion

Functional feedback should be fast enough to preserve perceived responsiveness.

Examples:

- button state
- checkbox
- menu toggle
- tooltip

## 3. Standard Motion

Use for:

- cards
- navigation
- drawers
- moderate transitions

## 4. Cinematic Motion

Use sparingly for:

- hero entrance
- editorial transitions
- campaign sequences
- page transitions

## 5. Easing Families

Potential semantic easing:

```text
ease.standard
ease.emphasized
ease.enter
ease.exit
ease.spring
ease.linear
```

## 6. General Rule

Avoid making every animation use the same easing curve.

The curve should communicate the physical role.

## 7. Spring

Spring-like motion may be used for:

- magnetic interactions
- draggable elements
- tactile controls

Do not use spring animation for every UI transition.

## 8. Reduced Motion

When reduced motion is active:

- replace movement with opacity where appropriate
- remove parallax
- remove magnetic effects
- remove decorative looping
- shorten transitions

## 9. Acceptance Criteria

Every production animation must map to semantic timing/easing tokens.
