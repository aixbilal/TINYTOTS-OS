# TinyTots Reduced Motion & Accessibility Motion

## 1. Requirement

Motion must never be the only way a user understands state or navigation.

## 2. Reduced Motion

Respect the user's system preference.

At minimum:

- remove parallax
- disable magnetic pointer movement
- stop decorative loops
- simplify page transitions
- remove large transforms
- preserve state changes

## 3. Focus

Focus transitions must remain visible.

Do not hide focus indicators during animated states.

## 4. Vestibular Considerations

Avoid:

- large continuous movement
- aggressive zoom
- rapid perspective shifts
- repeated spinning
- excessive depth movement

## 5. Loading

Do not use infinite animation as the only indication that content is loading if a progress/status message is possible.

## 6. Interaction

Users should be able to:

- close overlays
- navigate
- submit forms
- add products
- use search

without requiring precise pointer motion.

## 7. Testing

Test with:

- reduced motion enabled
- keyboard only
- touch
- screen reader where appropriate

## 8. Acceptance Criteria

The complete experience remains understandable and functional with motion effectively disabled.
