# TinyTots Typography Motion System

## 1. Philosophy

Typography animation should feel editorial, not like a motion-design demo.

## 2. Allowed Techniques

- fade + translate
- clip reveal
- line reveal
- subtle tracking change
- masked entrance

## 3. Hero Headlines

Hero text may use staged entrance:

```text
headline
→ supporting line
→ CTA
```

## 4. Body Copy

Body text should rarely animate line-by-line.

## 5. Navigation

Navigation text should prioritize immediate readability.

## 6. Scramble / Glitch

Avoid as a permanent TinyTots pattern.

It conflicts with the calm premium direction unless used for a very specific campaign concept.

## 7. Large Display Type

Large typography may have subtle movement during editorial transitions.

## 8. Accessibility

Text must remain readable if animation fails or is disabled.

## 9. Acceptance Criteria

No essential information may depend on text animation.
