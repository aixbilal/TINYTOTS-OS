# TinyTots Experimental UI Library Evaluation

## 1. Purpose

External UI libraries can accelerate experimentation, but TinyTots must not become a collage of third-party effects.

## 2. Candidate Sources

Examples:

- Vengeance UI
- Magic UI
- Forge UI
- Lore UI
- UIverse
- other curated interaction libraries

The list is not an approval list.

## 3. Evaluation Matrix

Every candidate component should be assessed on:

```text
BRAND FIT
VISUAL QUALITY
ACCESSIBILITY
RESPONSIVENESS
PERFORMANCE
DEPENDENCY COST
MAINTAINABILITY
CUSTOMIZATION
ORIGINALITY RISK
```

## 4. Preferred Process

```text
REFERENCE
↓
PROTOTYPE
↓
TINY TOTS ADAPTATION
↓
ACCESSIBILITY TEST
↓
PERFORMANCE TEST
↓
APPROVAL
↓
PRODUCTION
```

## 5. Do Not

Do not directly paste a library component into production because it looks impressive.

## 6. Adaptation

Approved effects should be modified to match:

- TinyTots colors
- typography
- timing
- geometry
- density
- interaction behavior

## 7. Dependency Rule

If a small effect can be implemented reliably with CSS/React without a large dependency, prefer the simpler implementation.

## 8. Acceptance Criteria

Every external effect must have a documented reason for inclusion.
