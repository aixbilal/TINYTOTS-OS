# TinyTots Microinteraction System

## 1. Purpose

Microinteractions provide tactile quality.

## 2. Button

Potential:

```text
REST
→ hover response
→ press
→ settle
```

## 3. Link

Use restrained:

- underline transition
- opacity shift
- directional movement

## 4. Icon

Examples:

- chevron rotation
- cart count transition
- search expansion
- menu transformation

## 5. Product Card

Potential:

- image crossfade
- slight scale
- quick-action reveal

## 6. Cart

Potential:

- item confirmation
- count transition
- mini-cart reveal

## 7. Form

Use subtle feedback for:

- focus
- validation
- success

## 8. Loading

Loading animation must communicate waiting.

Avoid decorative loaders that appear unrelated to the operation.

## 9. Cursor

Custom cursor behavior may be explored on desktop.

It must not replace standard cursor functionality or reduce usability.

## 10. Acceptance Criteria

Microinteractions should be noticeable after repeated use but not distracting on first exposure.
