# TinyTots Scroll Interaction System

## 1. Purpose

Scroll should reveal content naturally rather than become an obstacle course.

## 2. Allowed Scroll Behaviors

- reveal
- fade
- subtle translation
- image parallax
- scale settling
- sticky storytelling
- progress indicators where useful

## 3. Reveal

Content may enter as it becomes relevant.

Do not animate every tiny element individually.

## 4. Parallax

Use subtle relative movement.

Avoid extreme offsets that make content feel detached from the page.

## 5. Sticky Sections

Sticky storytelling may be used for:

- collection stories
- campaign narratives
- product detail sequences

It requires a mobile fallback.

## 6. Scroll Velocity

Animation should not become unstable when the user scrolls rapidly.

## 7. Long Pages

Avoid stacking too many scroll-triggered effects.

A page with five consecutive animated sections can feel heavier than a static page.

## 8. Performance

Prefer transform and opacity.

Avoid repeatedly animating layout properties.

## 9. Accessibility

Reduced-motion mode should remove or simplify scroll-linked effects.

## 10. Acceptance Criteria

The page remains fully understandable when all scroll animation is disabled.
