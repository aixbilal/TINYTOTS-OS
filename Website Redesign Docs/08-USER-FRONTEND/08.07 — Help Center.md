# TinyTots User Frontend — Help Center

## Purpose

The Help Center provides fast answers and routes customers to support.

## UX Priority

```text
FIND ANSWER
>
UNDERSTAND
>
TAKE ACTION
```

## Structure

```text
HELP HERO / SEARCH
↓
POPULAR QUESTIONS
↓
CATEGORY GRID
↓
CONTACT SUPPORT
```

## Search

Help search should be distinct from product search while maintaining consistent interaction patterns.

## Categories

Potential categories:

- Orders
- Shipping
- Returns
- Payments
- Products
- Account

Only include categories supported by actual content.

## Article

Articles should use:

- clear heading
- concise sections
- readable typography
- related questions
- contact path

## Visual Design

Premium does not mean difficult to scan.

Utility content requires strong readability.

## Motion

Minimal.

## Definition of Done

A customer can find an answer faster than contacting support for a standard question.
