# TinyTots User Frontend — Size Guide

## Purpose

The Size Guide reduces purchase uncertainty.

## Primary Requirement

Measurements and sizing information must come from verified TinyTots product/business data.

Do not invent measurements.

## Structure

```text
TITLE
↓
HOW TO MEASURE
↓
SIZE TABLE
↓
FIT NOTES
↓
AGE / SIZE CONTEXT WHERE VERIFIED
↓
CONTACT SUPPORT
```

## Table

The table must remain readable on mobile.

Potential solutions:

- responsive table
- horizontal scroll
- stacked groups

Do not make users zoom the entire page.

## Visuals

Measurement illustrations may be used if accurate.

## Product Context

Where accessed from a product page, preserve a path back to the product.

## Motion

Minimal.

## Accessibility

Tables require:

- correct headings
- readable labels
- sufficient contrast
- keyboard accessibility

## Definition of Done

A customer can determine the appropriate size using verified information without confusion.
