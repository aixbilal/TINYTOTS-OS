# TinyTots User Frontend — Products

## Purpose

The Products page is the primary catalog discovery surface.

## Primary Objectives

- browse efficiently
- understand product hierarchy
- filter
- sort
- search
- enter product details

## Structure

```text
HEADER
↓
PAGE TITLE / COLLECTION CONTEXT
↓
OPTIONAL EDITORIAL INTRO
↓
FILTER + SORT TOOLBAR
↓
PRODUCT GRID
↓
PAGINATION / LOAD MORE
↓
FOOTER
```

## Product Grid

Cards should maintain consistent:

- image ratio
- typography
- spacing
- price treatment
- interaction behavior

## Product Card

Required information:

- product image
- product name
- price
- relevant variant/availability information

Optional:

- secondary image
- badge
- quick add

## Hover

Desktop may use a secondary image or subtle movement.

No essential information may depend on hover.

## Filters

Use the global filter system from Phase 07.

## Empty State

If no products match:

- explain
- show active filters
- provide clear-all
- offer alternatives

## Motion

Allowed:

- card reveal
- image transition
- filter drawer transition

Avoid dramatic animation across the entire grid.

## Performance

Large catalogs must not render unnecessary heavy effects per card.

3D product experiences should not be mounted on every card by default.

## Definition of Done

A customer can scan a large product set quickly while the page still feels editorial and premium.
