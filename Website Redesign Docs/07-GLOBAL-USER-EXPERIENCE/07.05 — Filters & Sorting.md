# TinyTots Global UX — Filters & Sorting

## Purpose

Filtering reduces catalog complexity without making the interface feel like an administration tool.

## Potential Filters

Only expose attributes supported by actual product data.

Examples:

- category
- size
- color
- price
- collection
- availability

## Filter Presentation

Desktop may use:

- sidebar
- toolbar
- dropdown groups

Mobile should use:

- filter drawer
- clear grouping
- selected-state summary

## Selected Filters

Always make active filters visible.

Provide:

- individual removal
- clear all

## Sorting

Possible options:

- featured
- newest
- price low to high
- price high to low

Final options must reflect actual business logic.

## URL State

Filter and sorting state should be shareable where technically appropriate.

## Loading

Filtering should provide clear feedback without unnecessary full-page transitions.

## Empty Filter Result

Explain that the current combination returned no products.

Offer:

- clear filters
- broaden selection
- related category

## Accessibility

Filter controls require:

- labels
- keyboard support
- focus management
- mobile drawer focus control

## Definition of Done

A user can refine a large catalog quickly and always understand which filters are active.
