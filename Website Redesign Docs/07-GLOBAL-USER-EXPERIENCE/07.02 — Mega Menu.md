# TinyTots Global UX — Mega Menu

## Purpose

The mega menu is a high-value product discovery surface, not a decorative overlay.

## Goals

- expose major categories
- reduce navigation depth
- highlight collections
- support visual discovery
- preserve premium editorial feel

## Structure

Potential hierarchy:

```text
CATEGORY
├── Subcategory
├── Subcategory
└── Subcategory

FEATURED
└── Campaign / Collection
```

The final taxonomy must come from the actual catalog.

## Visual Direction

Use:

- generous whitespace
- clear typography
- restrained imagery
- strong hierarchy
- subtle motion

Avoid:

- dense link walls
- excessive cards
- decorative effects that compete with categories

## Opening

Desktop may support:

- hover intent
- click
- keyboard activation

Click should remain reliable.

## Closing

Close on:

- explicit close
- selecting a route
- clicking outside
- appropriate pointer exit behavior

Do not close unpredictably while the user moves between columns.

## Mobile

Do not force a desktop mega menu onto mobile.

Use a structured drill-down or accordion model.

## Images

Featured imagery should support navigation rather than become the focus.

## Accessibility

Requirements:

- keyboard reachable
- Escape closes
- focus remains controlled
- screen-reader structure
- visible focus

## Performance

Mega-menu images should not block page interaction.

## Definition of Done

The mega menu makes category discovery faster than navigating through multiple pages.
