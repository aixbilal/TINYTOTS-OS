# TinyTots Global UX — Header & Navigation

## Purpose

The header is the primary orientation and brand interface across the public website.

It must communicate premium fashion positioning while making product discovery immediate.

## Core Principles

1. Brand presence must be unmistakable.
2. Navigation must remain understandable.
3. Search must be easy to reach.
4. Cart/account access must remain visible.
5. Motion must never delay navigation.
6. Mobile and desktop are intentionally composed, not merely resized.

## Desktop Structure

Conceptual order:

```text
LOGO
→
PRIMARY NAVIGATION
→
SEARCH
→
ACCOUNT
→
CART
```

Exact placement follows the approved visual system from earlier phases.

## Navigation Categories

Primary categories should reflect actual catalog structure.

Possible grouping:

- New
- Girls
- Boys
- Baby
- Collections
- Sale

Do not invent categories without repository/catalog confirmation.

## Sticky Behavior

The header may:

- remain visible
- compress
- change contrast
- transition between transparent and solid states

Avoid aggressive hide/show behavior that causes orientation loss.

## Hero Integration

On cinematic pages, the header may initially overlay imagery.

Requirements:

- text remains readable
- logo remains legible
- controls remain accessible
- transition to solid header is predictable

## Mobile

Mobile navigation should prioritize:

1. menu
2. logo
3. search
4. cart

Account access may live inside the menu if space requires.

## Accessibility

Required:

- keyboard navigation
- visible focus
- semantic navigation landmarks
- logical tab order
- touch targets
- screen-reader labels

## Motion

Allowed:

- opacity
- transform
- underline
- menu transition
- header state transition

Avoid:

- long entrance animations
- delayed navigation
- excessive parallax

## Definition of Done

Users can identify where they are, search, navigate categories, access cart, and return home without confusion.
