# TinyTots Global UX — Account Experience

## Purpose

The account area provides customers with useful post-purchase and profile capabilities.

## Core Areas

Potential sections:

- profile
- orders
- order details
- saved items where supported
- addresses
- account settings

Only implement capabilities supported by the backend.

## Dashboard

The account dashboard should prioritize:

1. recent orders
2. order status
3. useful shortcuts

Avoid turning the account page into a marketing dashboard.

## Order History

Each order should expose:

- date
- order reference
- status
- total
- relevant action

## Order Details

Provide enough information to understand:

- products
- quantities
- pricing
- delivery
- status

## Authentication

Auth states must be clearly distinguished:

- signed out
- signing in
- signed in
- session expired
- authentication failure

## Sensitive Actions

Account changes require appropriate confirmation and validation.

## Mobile

Use clear stacked navigation or a compact account menu.

## Definition of Done

Customers can understand their account and orders without navigating through unnecessary layers.
