# SEO Requirements

## Purpose

Ensure the redesign improves visual quality without damaging discoverability.

## Technical Requirements

Maintain appropriate:

- semantic HTML
- page titles
- meta descriptions
- canonical URLs
- robots directives
- sitemap generation
- structured data where appropriate
- Open Graph metadata
- social metadata

## Product SEO

Product pages should expose meaningful:

- product name
- description
- availability
- price
- brand
- image information
- relevant structured data

Only publish structured data supported by actual application data.

## Headings

Use a logical hierarchy.

Do not use heading elements purely for visual styling.

## URLs

Do not change established URLs without a documented reason and redirect strategy.

## Rendering

SEO-critical content must be rendered in a way that search engines can reliably discover.

## Images

Provide meaningful alt text when the image conveys content.

Decorative images should not receive misleading descriptions.

## Internal Linking

Important pages should be reachable through crawlable links.

## Performance and SEO

Performance is part of the search experience.

Do not introduce heavy visual systems that materially degrade page delivery.

## AI Rule

Never invent metadata, structured-data fields, product claims, or URLs that are not supported by the repository or content source.
