# Task Specification Template

## Purpose

Provide a standard format for converting design decisions into implementation-ready AI tasks.

## Task

```text
TASK:
[One precise implementation objective]
```

## Context

```text
WHY:
[Why this change is required]
```

## Source Documents

```text
DOCUMENTS:
[Relevant documentation paths]
```

## Current State

```text
CURRENT:
[Verified current behavior]
```

## Target State

```text
TARGET:
[Exact desired behavior]
```

## Files

```text
PRIMARY FILES:
[Exact files expected to change]

SECONDARY FILES:
[Potential supporting files]
```

## Constraints

```text
DO NOT:
[Things that must remain unchanged]

MUST:
[Required implementation conditions]
```

## Visual Requirements

Include only concrete requirements such as:

- layout
- spacing
- typography
- color
- imagery
- responsive behavior
- interaction
- motion
- 3D behavior

## Functional Requirements

Specify:

- states
- user actions
- data behavior
- errors
- loading
- fallback behavior

## Performance Requirements

Specify relevant limits or expectations:

- lazy loading
- bundle impact
- animation constraints
- image optimization
- 3D constraints

## Accessibility Requirements

Specify relevant:

- keyboard behavior
- focus behavior
- reduced motion
- semantic structure
- labels

## Acceptance Criteria

The task is complete when:

1. [criterion]
2. [criterion]
3. [criterion]

## Validation

```text
RUN:
[typecheck / lint / build / tests / visual inspection]
```

## Reporting

The implementation agent must report:

- files changed
- behavior changed
- validation performed
- unresolved issues
