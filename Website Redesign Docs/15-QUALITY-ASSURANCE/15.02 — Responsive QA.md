# Responsive QA

## Purpose

Verify that the premium experience remains coherent and usable across desktop, tablet, and mobile.

## Required Viewports

At minimum evaluate:

```text
Desktop
Tablet
Mobile
```

Use representative real-device testing where practical.

## Check

### Layout

Verify:

- no horizontal overflow
- correct container widths
- correct section spacing
- correct grid behavior
- correct stacking
- correct image crops

### Typography

Verify:

- readable body text
- appropriate display scaling
- no unexpected wrapping
- no clipped text
- no excessive line lengths

### Navigation

Check:

- desktop navigation
- mobile navigation
- mega menu behavior
- search
- account
- cart

### Touch

Verify:

- controls are easy to tap
- swipe interactions work
- hover-only functionality is not required
- scrolling remains natural

## Mobile Principle

Mobile is not a shrunk desktop.

Use intentional mobile compositions where necessary.

## Responsive Motion

Check that animation remains:

- smooth
- useful
- lightweight
- appropriate to available screen space

## Acceptance

All primary journeys must remain functional and visually coherent at supported viewport sizes.
