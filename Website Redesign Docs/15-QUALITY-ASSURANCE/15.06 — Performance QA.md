# Performance QA

## Purpose

Ensure the redesigned site feels fast despite premium imagery, animation, and optional 3D.

## Core Metrics

Evaluate appropriate production performance indicators including:

- LCP
- INP
- CLS
- JavaScript execution
- image weight
- font loading
- third-party scripts
- WebGL cost

## Network Testing

Test representative:

- fast connection
- average mobile connection
- slow connection

## Device Testing

At minimum include:

- modern desktop
- mid-range mobile
- lower-powered mobile where available

## Images

Check:

- responsive sizing
- compression
- lazy loading
- priority loading
- oversized assets

## JavaScript

Check:

- bundle size
- unnecessary dependencies
- hydration cost
- client-side rendering cost
- unused code

## Animation

Check for:

- frame drops
- layout-triggering animation
- excessive blur
- expensive filters
- continuous GPU work

## 3D

Check:

- scene load
- asset load
- memory
- frame rate
- fallback behavior

## Acceptance

Performance regressions caused by visual enhancements must be identified and either fixed, reduced, or explicitly approved.
