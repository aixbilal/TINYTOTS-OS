# Visual QA

## Purpose

Verify that the implemented website matches the approved TinyTots visual system and does not drift into generic, noisy, or reference-brand imitation.

## QA Scope

Check:

- color
- typography
- spacing
- layout
- imagery
- component consistency
- hierarchy
- borders
- shadows
- icons
- buttons
- cards
- navigation
- empty states
- loading states

## Visual Hierarchy

Confirm:

```text
PRIMARY MESSAGE
↓
PRIMARY VISUAL
↓
SECONDARY INFORMATION
↓
ACTION
↓
SUPPORTING CONTENT
```

Nothing should compete unnecessarily with the primary purpose of a section.

## Brand Direction

The interface should remain:

- premium
- editorial
- warm
- modern
- restrained
- child-focused

It must not become:

- childish
- generic luxury
- visually noisy
- effect-driven
- derivative of a reference brand

## Typography

Verify:

- correct font family
- correct weight
- correct hierarchy
- correct line height
- consistent tracking
- responsive scaling

## Imagery

Check:

- correct aspect ratios
- correct crop
- correct focal point
- image quality
- loading behavior
- no accidental stretching
- no visual competition with UI

## Component Consistency

Compare repeated components across pages.

Examples:

- buttons
- product cards
- inputs
- navigation
- cards
- modal surfaces

## Review Method

Test both:

1. side-by-side against approved reference/design documentation
2. independently for overall brand coherence

## Acceptance

No major visual inconsistency should remain in primary user flows.
