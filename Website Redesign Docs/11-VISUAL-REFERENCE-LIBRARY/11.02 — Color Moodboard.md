# Color Moodboard

## Purpose

Establish the visual color territory for the premium TinyTots web system.

## Core Direction

The palette should support a premium black/neutral foundation while allowing the product photography and campaign imagery to provide controlled color.

## Primary Territory

Conceptual palette:

```text
DEEP BLACK
OFF-BLACK
WARM WHITE
IVORY
STONE
SOFT TAUPE
CHARCOAL
```

Exact production tokens remain governed by the design-system documentation.

## Accent Philosophy

Accents should be rare and purposeful.

Potential sources:

- campaign-specific colors
- product imagery
- restrained warm tones
- seasonal editorial palettes

Do not create a permanent rainbow accent system.

## Photography Relationship

The UI should often remain neutral while product photography provides visual richness.

This prevents:

```text
COLORFUL PRODUCT
+
COLORFUL UI
=
VISUAL NOISE
```

## Dark Sections

Dark backgrounds may be used for:

- hero moments
- editorial transitions
- campaign sections
- premium product storytelling

Do not make every section dark.

## Contrast

All functional text and controls require accessible contrast.

## Reference Collection

Moodboard references should include:

- neutral fashion layouts
- monochrome editorial compositions
- warm natural tones
- black/ivory luxury interfaces

## Rejection Criteria

Reject palettes that feel:

- toy-store
- overly childish
- synthetic
- neon
- excessively saturated

## Definition of Done

The color system makes TinyTots feel premium before imagery or animation is considered.
