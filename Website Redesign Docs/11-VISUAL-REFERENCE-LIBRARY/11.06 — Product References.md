# Product Visual References

## Purpose

Define how products should be presented across catalog and product-detail experiences.

## Product Listing

Reference qualities:

- clean grids
- consistent image ratios
- restrained typography
- strong whitespace
- subtle hover states

## Product Detail

Reference qualities:

- large media
- clear information hierarchy
- strong purchase CTA
- premium gallery
- detailed product storytelling

## Product Photography

Prefer:

- accurate color
- consistent lighting
- clean composition
- useful alternate angles

## 3D

Potential product 3D references may include:

- interactive rotation
- material inspection
- subtle depth

Only use where actual product assets justify it.

## Cards

Avoid turning every product into a visually complex animated object.

## Reference Evaluation

For each reference identify:

- grid behavior
- image treatment
- card interaction
- typography
- purchase hierarchy
- mobile behavior

## Definition of Done

Product references establish a premium shopping system that remains faster and clearer than a purely experimental design.
