# Typography Moodboard

## Purpose

Define the visual typography territory for TinyTots.

## Existing Direction

### Display

Playfair Display is the established editorial/display direction.

### UI / Body

Geist → Inter is the established primary UI/body direction.

### Technical

JetBrains Mono may be used selectively for:

- SKU
- technical identifiers
- operational metadata

## Hierarchy

Typography should create a strong contrast between:

```text
EDITORIAL
vs
UTILITY
```

## Display Character

Large headlines should feel:

- sophisticated
- calm
- fashion-oriented
- spacious

Avoid oversized typography used only for spectacle.

## Body Character

Body text should feel:

- neutral
- highly readable
- contemporary
- quiet

## Product Typography

Product names and prices require disciplined hierarchy.

Price should be immediately scannable.

## Admin Typography

Admin typography prioritizes information density and readability over editorial styling.

## Reference Collection

Include references demonstrating:

- serif/sans combinations
- large editorial headlines
- restrained product typography
- dense utility interfaces
- strong whitespace

## Avoid

- novelty display fonts
- too many font families
- excessive uppercase
- tiny metadata
- decorative typography that damages readability

## Definition of Done

Typography communicates premium positioning without sacrificing usability.
