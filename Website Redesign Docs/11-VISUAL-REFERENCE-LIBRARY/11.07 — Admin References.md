# Admin Visual References

## Purpose

Define the visual reference territory for the operational admin interface.

## Direction

The admin should feel:

- premium
- precise
- calm
- efficient
- information-rich
- professional

## Reference Categories

### Shell

Look for:

- excellent sidebar hierarchy
- clear active states
- restrained top bars

### Dashboard

Look for:

- useful metrics
- strong information grouping
- readable charts
- actionable alerts

### Tables

Look for:

- density control
- excellent alignment
- clear row actions
- scalable pagination/filtering

### Forms

Look for:

- clear field grouping
- strong validation
- predictable save behavior
- excellent editor layouts

### Media Management

Look for:

- asset previews
- upload progress
- crop/focal controls where required

## Avoid

- marketing-style hero sections
- excessive animation
- oversized decorative typography
- visual effects that reduce data density

## Reference Evaluation

Each reference must answer:

```text
Does this improve admin productivity?
```

If not, it is not a valid admin reference.

## Definition of Done

The admin has a coherent premium operational language distinct from the public storefront.
