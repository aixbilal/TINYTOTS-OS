# TinyTots Visual Reference Library — Master Moodboard

## Purpose

Define the overall visual world that every TinyTots web experience must belong to.

This document is a visual direction, not a collection of assets to copy.

## Brand Position

Target perception:

```text
PREMIUM
+
MODERN
+
EDITORIAL
+
CALM
+
CONFIDENT
+
CHILD-CENTRIC WITHOUT BEING CHILDISH
```

Reference territory may include premium fashion brands such as Zara Kids, Jacadi, and Ralph Lauren Children, but TinyTots must develop its own recognizable language.

## Emotional Keywords

- quiet luxury
- candid
- refined
- warm
- contemporary
- tactile
- confident
- understated
- editorial
- human

## Avoid

- generic children's-store aesthetics
- excessive primary colors
- cartoonish UI
- random gradients
- excessive glassmorphism
- neon cyberpunk effects
- gratuitous 3D
- animation on every element
- visual clutter

## Visual Composition

Favor:

- large photography
- strong negative space
- asymmetric editorial composition
- restrained typography
- generous margins
- intentional cropping
- high-quality product imagery

## Interaction Philosophy

Motion should create:

```text
DEPTH
>
CONTINUITY
>
DISCOVERY
```

not distraction.

## 3D Philosophy

3D is an occasional signature element.

It must have a reason to exist.

## Reference Selection Rule

Every reference image added to the library should answer at least one question:

- What should TinyTots look like?
- What should TinyTots feel like?
- How should a component behave?
- How should a transition work?
- How should depth be created?

## Final Test

If removing an effect makes the design better, remove the effect.
