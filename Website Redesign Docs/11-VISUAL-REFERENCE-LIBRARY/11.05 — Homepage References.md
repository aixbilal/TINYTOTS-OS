# Homepage Visual References

## Purpose

Collect references for the public homepage composition.

## Reference Categories

### Hero

Look for:

- cinematic photography
- strong negative space
- restrained typography
- confident CTA placement
- subtle motion

### Editorial Blocks

Look for:

- asymmetric layouts
- image/text balance
- generous spacing
- strong visual rhythm

### Product Sections

Look for:

- clean product grids
- premium card treatment
- subtle interaction
- editorial framing

### Brand Story

Look for:

- large imagery
- typography-led transitions
- visual storytelling

### Footer

Look for:

- strong final composition
- clear navigation
- premium closing moment

## Reference Evaluation

For every reference document:

```text
REFERENCE
→
WHAT WORKS
→
WHY IT WORKS
→
WHAT TO ADAPT
→
WHAT NOT TO COPY
```

## Motion

References may include:

- scroll reveals
- image transitions
- sticky transitions
- text choreography

Motion must remain subordinate to content.

## Definition of Done

The homepage reference set provides implementation-level visual direction rather than a gallery of attractive screenshots.
