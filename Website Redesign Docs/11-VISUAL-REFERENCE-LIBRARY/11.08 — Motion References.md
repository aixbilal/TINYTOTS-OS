# Motion Visual References

## Purpose

Create the visual reference library for TinyTots animation and interaction behavior.

## Motion Categories

### Micro Interaction

- button feedback
- hover
- active states
- cart updates

### Navigation

- menu reveal
- search overlay
- drawers
- transitions

### Editorial

- image reveal
- typography entrance
- section choreography

### Scroll

- controlled parallax
- sticky transitions
- progressive reveals

### 3D

- camera movement
- object rotation
- material interaction

## Reference Rule

Do not collect effects merely because they look impressive.

For every motion reference record:

- trigger
- duration character
- easing character
- affected elements
- purpose
- mobile behavior
- reduced-motion fallback

## Motion Hierarchy

```text
MICRO
↓
COMPONENT
↓
SECTION
↓
PAGE
↓
SIGNATURE
```

Not every layer needs animation.
