# 3D Visual References

## Purpose

Define the visual territory for selective 3D experiences.

## Core Principle

```text
3D IS A FEATURE, NOT THE BRAND.
```

The website should remain premium and fast without requiring WebGL.

## Reference Categories

### Product

- rotating product
- material inspection
- interactive garment/detail view

### Hero

- restrained spatial composition
- depth-based campaign element
- controlled camera movement

### Editorial

- abstract objects
- typography depth
- environmental scenes

### Navigation

Only consider 3D navigation if it materially improves discovery.

## Quality Bar

References should demonstrate:

- excellent lighting
- believable materials
- controlled camera
- restrained movement
- clean composition

Avoid:

- low-quality models
- excessive particles
- gaming aesthetics
- constant camera motion
- WebGL effects with no functional purpose

## Performance Reference

Every 3D reference should be evaluated against:

- model complexity
- texture weight
- draw calls
- mobile behavior
- loading strategy
- fallback

## Fallback

Every 3D concept requires a non-3D equivalent.

```text
3D AVAILABLE
→
ENHANCED EXPERIENCE

3D UNAVAILABLE / DISABLED
→
PREMIUM 2D EXPERIENCE
```

## Definition of Done

The 3D reference library identifies only experiences that can realistically meet TinyTots' premium visual and performance standards.
