# TinyTots 3D Fallback Strategy

## Purpose

3D must be progressive enhancement.

The website must remain complete without WebGL.

## Fallback Hierarchy

```text
FULL 3D
  ↓
REDUCED 3D
  ↓
STATIC 3D RENDER / IMAGE
  ↓
STANDARD PRODUCT IMAGE
```

The appropriate level depends on device capability and experience importance.

## WebGL Unavailable

Replace the canvas with an appropriate static visual.

Do not leave:

- blank space
- broken canvas
- loading spinner forever

## Reduced Motion

When reduced motion is requested:

- disable camera movement
- disable continuous rotation
- remove decorative particle movement
- minimize transitions
- provide static framing

## Mobile

Mobile may receive:

- simplified scene
- static image
- reduced interaction
- lower asset quality

The choice should be evidence-based rather than automatic.

## Low Performance

If performance is poor, degrade gracefully.

Possible strategies:

1. reduce pixel ratio
2. reduce scene complexity
3. disable post-processing
4. reduce animation
5. switch to static media

## Network Failure

If a 3D asset fails:

- preserve the page
- show fallback media
- optionally retry
- never block checkout/product information

## Accessibility

The 3D canvas cannot be the only source of important information.

Provide equivalent:

- product name
- product description
- controls outside the canvas where necessary
- meaningful media alternative

## SEO

Critical textual content must exist as normal HTML/content.

Do not place discoverability-critical content only inside WebGL.

## Browser Compatibility

The implementation must be tested across the project's supported browsers.

## QA Matrix

Test:

```text
WEBGL AVAILABLE
WEBGL UNAVAILABLE
FAST DEVICE
MID DEVICE
LOW-END DEVICE
DESKTOP
MOBILE
REDUCED MOTION
SLOW NETWORK
FAILED ASSET
TAB HIDDEN / RETURNED
```

## Definition of Done

A 3D experience is approved only if:

- the full version works
- fallback works
- reduced motion works
- mobile behavior works
- asset failure works
- core page remains functional
- performance has been measured
