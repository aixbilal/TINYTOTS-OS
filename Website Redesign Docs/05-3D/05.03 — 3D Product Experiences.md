# TinyTots 3D Product Experiences

## Purpose

3D can make selected products feel tangible and premium, but standard product photography remains the default source of truth unless actual 3D assets exist.

## Experience Types

### 1. Interactive Product Viewer

Potential capabilities:

- rotate
- inspect
- zoom
- controlled camera
- material/detail inspection

Use only when accurate 3D assets are available.

### 2. Material Exploration

Useful for products where:

- texture
- construction
- finish
- silhouette

are important.

### 3. Campaign Product Scene

A product can be placed in an art-directed 3D environment for a campaign.

The environment must support the collection narrative.

### 4. Hybrid Product Experience

Recommended starting direction:

```text
REAL PRODUCT PHOTOGRAPHY
+
SUBTLE DEPTH
+
OPTIONAL 3D DETAIL
```

This is safer than replacing all product photography with 3D.

## Product Accuracy

Never create a 3D product representation that materially misrepresents:

- color
- shape
- texture
- proportions
- construction
- branding

## Product Page Rule

The primary purchase path must work without 3D.

## Loading

3D product assets should load progressively.

Initial product information and primary media should not wait unnecessarily for the 3D scene.

## Controls

If controls are provided:

- rotate
- zoom
- reset

should be discoverable.

## Touch

Support:

- drag
- pinch where appropriate
- reset

without requiring hover.

## Motion

Object rotation should have bounded velocity and predictable stopping.

## Product Cards

Do not place heavy 3D canvases inside every product card by default.

A grid of WebGL canvases is likely to create unnecessary cost.

Prefer:

- static imagery
- lightweight hover media
- one selected 3D experience after user intent

## Acceptance Criteria

3D improves product understanding or desirability without slowing discovery or purchase.
