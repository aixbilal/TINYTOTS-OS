# TinyTots Reference Brand — COS

## Purpose

Quiet minimalism, whitespace, materiality, typography, editorial restraint. Use it to simplify rather than decorate.

This is a **principle reference, not a template**.

## Core Lessons

### Quiet Confidence
Premium design does not require constant stimulation.

### Space
Whitespace communicates calm, quality, confidence, and importance.

### Materiality
Fabric, texture, silhouette, light, and physical detail can carry the visual narrative.

### Editorial Simplicity
A restrained composition can feel more valuable than a heavily decorated interface.

## TinyTots Application

Use the reference primarily for:

- visual hierarchy
- brand storytelling
- composition
- interaction decisions
- photography direction
- premium perception

Specific application must remain consistent with TinyTots' governing design system.

## What Not to Copy

Do not reproduce:

- exact layouts
- exact typography
- exact photography
- brand-specific color systems
- proprietary visual signatures
- patterns that conflict with TinyTots usability, accessibility, or performance
