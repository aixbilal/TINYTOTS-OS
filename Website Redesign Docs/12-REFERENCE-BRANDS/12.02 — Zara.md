# TinyTots Reference Brand — Zara

## Purpose

Fashion-first commerce, editorial photography, product discovery, campaign-to-commerce continuity, restrained UI. Do not copy exact layouts or styling.

This is a **principle reference, not a template**.

## Core Lessons

### Fashion-First Commerce
Commerce can feel editorial while remaining easy to shop.

### Photography as Interface
Strong imagery can provide hierarchy without excessive UI decoration.

### Campaign-to-Commerce
Connect:

```text
CAMPAIGN → COLLECTION → PRODUCT → PURCHASE
```

### Product Discovery
Make catalog browsing visually engaging while preserving scanability.

### Restraint
Neutral UI allows garments and photography to provide the visual color.

## TinyTots Application

Use the reference primarily for:

- visual hierarchy
- brand storytelling
- composition
- interaction decisions
- photography direction
- premium perception

Specific application must remain consistent with TinyTots' governing design system.

## What Not to Copy

Do not reproduce:

- exact layouts
- exact typography
- exact photography
- brand-specific color systems
- proprietary visual signatures
- patterns that conflict with TinyTots usability, accessibility, or performance
