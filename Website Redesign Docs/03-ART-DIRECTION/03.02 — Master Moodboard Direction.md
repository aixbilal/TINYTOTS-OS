# TinyTots Master Moodboard Direction

## 1. Core Mood

The primary mood is:

> **Modern European children's fashion photographed with warmth and human emotion.**

This is a direction, not a requirement that all imagery be European in setting.

## 2. Moodboard Pillars

### Pillar A — Quiet Luxury

Visual references:

- architectural interiors
- restrained styling
- natural materials
- soft shadows
- minimal compositions

### Pillar B — Childhood

Visual references:

- movement
- curiosity
- genuine expressions
- play
- sibling/friend interactions

### Pillar C — Fashion Editorial

Visual references:

- deliberate styling
- confident poses
- strong crops
- unusual but elegant framing
- fashion-magazine composition

### Pillar D — Warm Human Life

Visual references:

- family environments
- outdoor moments
- candid interactions
- tactile materials
- natural imperfections

### Pillar E — Contemporary Digital

Visual references:

- clean typography
- large media
- subtle transitions
- strong grid systems
- controlled interactive depth

## 3. Mood Ratio

Conceptual balance:

```text
QUIET LUXURY       █████████
CHILDHOOD          ███████
FASHION EDITORIAL  █████████
HUMAN WARMTH       █████████
DIGITAL NOVELTY    ████
```

Digital novelty is deliberately lower.

## 4. Moodboard Rule

A moodboard image is approved because of a **specific principle**, not simply because it looks attractive.

Every selected reference must record:

```text
IMAGE
SOURCE
WHAT WORKS
TINY TOTS APPLICATION
WHAT NOT TO COPY
```

## 5. Visual Tension

The brand benefits from controlled contrasts:

- childlike subject + sophisticated styling
- warm imagery + restrained UI
- soft photography + precise typography
- playful movement + calm composition
- premium environment + genuine expression

## 6. Moodboard Anti-Pattern

Do not build a moodboard containing only:

- luxury interiors
- fashion models
- black backgrounds
- expensive-looking objects

It must still communicate childhood.

## 7. Final Moodboard Test

Remove the TinyTots logo.

If the references still communicate:

> premium children's fashion

the direction is working.
