# TinyTots Asset Specification & Generation Briefs

## 1. Purpose

This document defines the standard for creating new visual assets.

## 2. Asset Classes

### Brand

- logo
- favicon
- marks
- typography assets

### Hero

- homepage hero
- campaign hero
- collection hero

### Editorial

- story images
- lifestyle photography
- detail imagery

### Product

- catalog images
- alternate views
- detail images

### Utility

- empty-state imagery
- help illustrations if approved
- error/success visuals

## 3. Generation Brief Template

Every generated visual should specify:

```text
PURPOSE
SUBJECT
AGE/PRODUCT CONTEXT
LOCATION
WARDROBE
LIGHTING
MOOD
CAMERA/COMPOSITION
FOCAL POINT
TEXT-SAFE AREA
ASPECT RATIO
BACKGROUND
COLOR DIRECTION
NEGATIVE REQUIREMENTS
OUTPUT QUALITY
```

## 4. Hero Brief Example Structure

```text
Premium children's fashion campaign image.
Warm neutral environment.
Natural directional light.
Authentic child expression.
Sophisticated styling.
Large negative space for headline.
No visible logos.
No text in image.
No distracting props.
Editorial fashion photography.
```

This is a structural example, not a final generation prompt.

## 5. Negative Requirements

Where applicable:

- no watermark
- no generated text
- no distorted hands
- no duplicated limbs
- no clothing artifacts
- no incorrect product construction
- no random logos
- no excessive skin retouching

## 6. Asset Quality

Reject assets with:

- obvious AI artifacts
- incorrect garment details
- unnatural anatomy
- inconsistent lighting
- poor crop
- excessive sharpening
- compression artifacts

## 7. Naming

Use descriptive asset names:

```text
homepage-hero-aw26-desktop.webp
homepage-hero-aw26-mobile.webp
collection-01-editorial-01.webp
```

Avoid:

```text
img1.png
finalfinal2.jpg
new-new.webp
```

## 8. Delivery Variants

Where required:

- desktop
- tablet
- mobile
- retina/high-density

## 9. Acceptance Criteria

Every production asset must have a known purpose and component destination.
