# TinyTots Design System — Cards & Surfaces

## 1. Philosophy

Not everything is a card.

Use cards when grouping content improves comprehension.

## 2. User Card Types

Potential patterns:

- product card
- editorial card
- campaign card
- testimonial card
- content card

## 3. Product Card Priority

Product card hierarchy:

```text
IMAGE
↓
PRODUCT NAME
↓
PRICE
↓
OPTIONAL METADATA
```

The image should dominate.

## 4. Hover

Possible behaviors:

- alternate image
- subtle image scale
- metadata reveal
- cursor/tactile response

Do not combine all behaviors automatically.

## 5. Admin Card Types

Potential patterns:

- KPI card
- status card
- summary card
- action card

## 6. Surfaces

Define:

- canvas
- section
- elevated
- overlay
- inverse

## 7. Border Usage

Borders should be used to clarify grouping, not decorate every edge.

## 8. Acceptance Criteria

Every card must have a reason to exist as a bounded component.
