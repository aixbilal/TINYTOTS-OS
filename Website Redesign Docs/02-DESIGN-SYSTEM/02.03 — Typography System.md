# TinyTots Design System — Typography System

## 1. Typography Strategy

Typography must carry a major portion of the brand identity.

The system should combine:

- editorial character
- modern interface readability
- strong hierarchy

## 2. Current Brand Direction

The established brand direction includes:

- **Playfair Display** as a display/editorial candidate
- **Geist / Inter** as UI/body candidates
- **JetBrains Mono** for SKU or technical identifiers where useful

These are candidates/foundations, not permission to use every font everywhere.

## 3. Roles

### Display

Used for:

- hero headlines
- editorial statements
- major campaign titles

### Heading

Used for:

- page titles
- section headings
- product names where appropriate

### Body

Used for:

- descriptions
- support content
- UI explanations
- long-form content

### Label

Used for:

- metadata
- filters
- navigation labels
- badges

### Mono

Used selectively for:

- SKU
- order/reference identifiers
- technical admin values

## 4. Type Scale

The production scale should use semantic names:

```text
display-xl
display-lg
display-md
heading-xl
heading-lg
heading-md
heading-sm
body-lg
body-md
body-sm
label-lg
label-md
label-sm
caption
mono
```

Exact sizes should be finalized with responsive testing.

## 5. Weight

Avoid excessive weight variation.

Preferred range:

- regular
- medium
- semibold

Bold should be reserved for deliberate emphasis.

## 6. Line Length

Long-form text should use a constrained measure.

Do not allow paragraphs to span the entire desktop viewport.

## 7. Editorial Typography

Large editorial type may intentionally exceed normal UI sizes.

However:

- wrapping must be tested
- mobile behavior must be specified
- accessibility must remain acceptable

## 8. Letter Spacing

Use tracking intentionally.

Avoid excessive uppercase tracking.

## 9. Typography and Motion

Text animation must preserve readability.

Avoid:

- letter-by-letter animation for ordinary UI
- constant text scrambling
- animations that delay reading

## 10. Admin Typography

Admin should prioritize:

- fast scanning
- numeric clarity
- table readability
- compact labels

Editorial display typography should be used sparingly.

## 11. Acceptance Criteria

Every text style used in production must map to a documented semantic typography token.
