# TinyTots Design System — Shape Language

## 1. Shape Philosophy

The interface should avoid becoming excessively rounded.

Premium fashion interfaces often benefit from architectural geometry and restraint.

## 2. Radius Hierarchy

Use a small controlled radius family:

```text
radius-none
radius-sm
radius-md
radius-lg
radius-pill
```

## 3. Default Philosophy

Prefer:

- subtle radius for controls
- moderate radius for selected cards
- full radius only where semantically appropriate

## 4. Avoid

Do not make:

- every section a rounded container
- every card pill-shaped
- every image heavily rounded
- every button excessively bubbly

## 5. Product Images

Product image radius should be determined by art direction and page context.

Editorial full-bleed images may have no radius.

Product cards may use a subtle radius.

## 6. Admin

Admin components should generally use tighter geometry for efficient information density.

## 7. Shape as Brand

The TinyTots signature should come more from:

- typography
- photography
- whitespace
- composition

than from a distinctive universal radius.

## 8. Acceptance Criteria

Shape choices must be consistent across components unless the composition has a documented reason to differ.
