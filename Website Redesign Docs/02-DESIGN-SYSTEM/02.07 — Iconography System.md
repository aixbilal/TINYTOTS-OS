# TinyTots Design System — Iconography

## 1. Philosophy

Icons should support comprehension rather than become decoration.

## 2. Style

Use one coherent icon family.

Avoid mixing:

- filled icons
- outlined icons
- hand-drawn icons
- 3D icons

without a documented reason.

## 3. Weight

Icon stroke weight should visually align with body typography.

## 4. Sizes

Define semantic sizes:

```text
icon-xs
icon-sm
icon-md
icon-lg
icon-xl
```

## 5. Controls

Interactive icons must include:

- hover
- focus
- active
- disabled

where applicable.

## 6. Icon Buttons

Icon-only controls require:

- accessible label
- sufficient touch target
- visible focus state

## 7. Animation

Icon animation should be minimal.

Good:

- chevron rotation
- cart state change
- menu transition

Bad:

- constant spinning
- bouncing
- decorative loops

## 8. Admin

Icons should make navigation scanning faster.

Do not rely on icons alone for critical navigation meaning.

## 9. Acceptance Criteria

Every icon source must be documented in implementation dependencies.
