# TinyTots Interaction Reference — Aceternity UI

## Purpose

Evaluate Aceternity UI for modern React interaction patterns and motion-heavy components.

## Potentially Relevant Patterns

- background effects
- spotlight
- text reveals
- card interactions
- hover effects
- animated navigation
- scroll-driven sections

## TinyTots Fit

### Strong Fit

- selected text reveals
- subtle card hover
- editorial background depth
- campaign transitions

### Adapt

Strongly stylized effects should be reduced in:

- intensity
- frequency
- contrast
- movement

## 3D Boundary

Aceternity-style visual effects must not be confused with genuine 3D.

If an effect can be achieved efficiently with CSS or standard motion, do not introduce WebGL.

## Performance

Avoid stacking:

```text
large background effect
+
particles
+
blur
+
3D
+
continuous scroll animation
```

in the same viewport without a measured reason.
