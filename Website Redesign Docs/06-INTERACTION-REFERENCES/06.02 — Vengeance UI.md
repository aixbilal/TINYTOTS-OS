# TinyTots Interaction Reference — Vengeance UI

## Purpose

Evaluate Vengeance UI as a source for visually aggressive and experimental interaction concepts.

## Potentially Useful Areas

- cursor interactions
- magnetic movement
- animated navigation
- distortion
- hover choreography
- immersive transitions
- visual effects

## TinyTots Fit

### Strong Fit

Only when used selectively for:

- campaign hero
- high-impact CTA
- editorial transition
- special product interaction

### Adapt

Vengeance-style effects should be softened.

Preferred direction:

```text
aggressive
→
controlled

dark-tech
→
fashion-editorial

constant
→
event-driven
```

### Reject

- effects on every button
- persistent cursor gimmicks
- excessive distortion
- overwhelming transitions
- interactions that make navigation slower

## Cursor

A custom cursor can be considered only for desktop.

It must never replace:

- native pointer behavior
- visible focus
- touch interaction

## Motion

Motion must remain subordinate to content.

## Performance

Heavy effects should be isolated to specific sections.

## Decision

**REFERENCE / HIGH-SELECTIVITY**

Use Vengeance as inspiration for exceptional moments, not as the default interaction language.
