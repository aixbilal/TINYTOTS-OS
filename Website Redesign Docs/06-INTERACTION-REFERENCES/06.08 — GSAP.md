# TinyTots Interaction Reference — GSAP

## Purpose

GSAP is evaluated for advanced timeline choreography and interactions where simpler React motion is insufficient.

## Best Use Cases

- cinematic hero sequences
- scroll choreography
- complex timelines
- SVG animation
- advanced image transitions
- pinned storytelling sections
- coordinated multi-element sequences

## Strong Fit

GSAP should be considered when the interaction is genuinely timeline-driven.

## Avoid

Do not use GSAP for:

- basic hover
- simple fade
- simple modal transition
- ordinary button feedback

Use simpler mechanisms for simple problems.

## ScrollTrigger

Potentially useful for:

- editorial storytelling
- campaign sequences
- controlled scroll scenes

Requirements:

- reduced-motion fallback
- mobile strategy
- interruption behavior
- performance testing

## Integration

GSAP should not become a second competing animation architecture.

Establish a clear division:

```text
Simple UI motion
→ Motion.dev / CSS

Complex choreography
→ GSAP

3D rendering
→ Three.js / R3F
```

## Decision

**ADVANCED MOTION / CHOREOGRAPHY TOOL**
