# TinyTots Interaction Reference — Motion.dev

## Purpose

Motion.dev is evaluated as a practical motion implementation foundation for React interfaces.

## Potential Uses

- enter/exit transitions
- layout transitions
- gestures
- hover/tap states
- shared transitions
- presence
- scroll-linked motion

## Why It Fits

Motion.dev can provide structured animation without requiring every interaction to become a custom animation system.

## Use For

Recommended candidates:

- menus
- drawers
- modals
- product interactions
- microinteractions
- page transitions
- editorial reveals

## Avoid

Do not animate everything simply because the library makes it easy.

## Reduced Motion

Every Motion.dev implementation must respect the project's reduced-motion contract.

## Component Rule

Motion should be encapsulated inside reusable components rather than scattered throughout page files.

## Performance

Prefer transform/opacity where possible.

Measure layout-heavy animations before approving them.
