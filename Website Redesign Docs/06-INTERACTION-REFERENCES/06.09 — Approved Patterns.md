# TinyTots Approved Interaction Patterns

## Purpose

This document is the final filter between external inspiration and production implementation.

A pattern is approved only when it satisfies:

```text
BRAND FIT
+
UX VALUE
+
ACCESSIBILITY
+
PERFORMANCE
+
IMPLEMENTATION VALUE
```

## Tier 1 — Core Patterns

These may be used throughout the site.

### Subtle Hover

- image transition
- slight scale
- controlled opacity
- underline movement

### Button Feedback

- restrained movement
- background transition
- border transition
- tactile press state

### Menu Transitions

- short slide/fade
- clear hierarchy
- predictable close

### Drawer

- smooth entrance
- backdrop
- focus management

### Product Image Swap

- primary → secondary image
- short crossfade

## Tier 2 — Editorial Patterns

Use selectively.

### Text Reveal

For:

- hero
- editorial headings
- campaign sections

### Image Reveal

Use clip/mask/reveal where it improves storytelling.

### Parallax

Use subtle depth, not exaggerated movement.

### Scroll Choreography

Use for major storytelling sequences.

## Tier 3 — Exceptional Patterns

Use rarely.

### Magnetic CTA

Desktop only where appropriate.

### Gooey / Liquid Transition

Only for campaign-level experiences.

### Cursor Enhancement

Desktop only and never required for usability.

### Image Distortion

Only when content remains understandable.

### 3D Interaction

Only where documented in Phase 05.

## Pattern Combination Rule

Do not stack multiple high-intensity effects automatically.

Preferred:

```text
1 hero
+
1 primary motion concept
+
subtle microinteractions
```

rather than:

```text
hero
+
particles
+
cursor
+
gooey
+
parallax
+
distortion
+
3D
```

## Global Rule

The interaction should be memorable because of its choreography and restraint, not because of the number of effects.

## Approval Status

These patterns are approved as design directions, subject to implementation and performance QA.
