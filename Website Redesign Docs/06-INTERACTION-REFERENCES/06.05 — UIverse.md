# TinyTots Interaction Reference — UIverse

## Purpose

UIverse is evaluated as a source of interaction and CSS inspiration.

## Useful Areas

Potentially useful:

- buttons
- inputs
- hover states
- loaders
- cards
- toggles
- microinteractions

## TinyTots Fit

UIverse is most useful for discovering small interaction ideas.

## Adopt

Simple patterns with:

- clear purpose
- low runtime cost
- good accessibility

## Adapt

Any pattern that uses:

- neon
- high contrast glow
- playful gradients
- exaggerated movement

must be translated into the TinyTots visual language.

## Reject

Avoid copying patterns merely because they look impressive in isolation.

## CSS Rule

Prefer extracting the interaction concept and rebuilding it using TinyTots tokens rather than copying arbitrary CSS.

## Decision

**REFERENCE / MICROINTERACTION SOURCE**
