# TinyTots Interaction Reference — Lore UI

## Purpose

Evaluate Lore UI for atmospheric, editorial, or visually expressive interaction patterns where applicable.

## Potential Fit

Strongest possible use cases:

- storytelling sections
- editorial navigation
- campaign pages
- visual transitions

## Adopt

Only patterns that maintain:

- readability
- hierarchy
- restraint

## Adapt

Atmospheric effects should be aligned with:

- TinyTots typography
- neutral palette
- photography
- premium whitespace
- restrained motion

## Reject

- visual effects without narrative purpose
- excessive background activity
- effects that reduce text contrast
- decorative complexity in utility flows

## Editorial Rule

A storytelling page can carry more motion than a checkout or help page.
