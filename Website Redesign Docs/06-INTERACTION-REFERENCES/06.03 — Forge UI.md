# TinyTots Interaction Reference — Forge UI

## Purpose

Forge UI is evaluated for reusable interface patterns and polished interaction ideas.

## Evaluation Areas

Review relevant patterns for:

- buttons
- cards
- navigation
- forms
- overlays
- transitions
- responsive behavior

## TinyTots Fit

### Adopt

Patterns that improve:

- clarity
- hierarchy
- responsiveness
- interaction feedback

### Adapt

Patterns with strong visual effects should be translated into the TinyTots visual system.

### Reject

Components that introduce:

- unnecessary complexity
- excessive decoration
- inconsistent interaction models
- dependencies without meaningful value

## Implementation Rule

The repository's existing component architecture remains the source of truth.

Do not import an entire UI library when only one pattern is required.

## API Rule

Any adopted pattern must conform to:

- TinyTots tokens
- component naming
- accessibility contracts
- motion tokens
- responsive rules
