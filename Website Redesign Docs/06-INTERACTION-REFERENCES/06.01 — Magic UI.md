# TinyTots Interaction Reference — Magic UI

## Purpose

Magic UI is evaluated as a source of implementation patterns, not as a visual identity to copy wholesale.

## Useful Reference Categories

Potentially relevant patterns include:

- animated buttons
- text effects
- shimmer effects
- borders
- hover interactions
- subtle reveal effects
- spotlight-style effects
- marquee systems

## TinyTots Fit

### Strong Fit

- restrained button hover
- subtle text reveal
- premium loading treatment
- controlled border animation
- selected campaign effects

### Adapt

- marquee
- spotlight
- shimmer
- glow

These should be stripped of excessive "tech-demo" styling.

### Reject by Default

- neon-heavy effects
- constant decorative movement
- excessive gradients
- effects that compete with product imagery

## Brand Translation

Magic UI patterns should be converted toward:

```text
TECHNICAL EFFECT
→
EDITORIAL EFFECT
```

Example:

```text
bright animated glow
→
soft light sweep
```

## Performance

Do not introduce a dependency solely for a trivial CSS effect.

Prefer:

- CSS
- existing motion primitives
- lightweight React animation

where sufficient.

## Accessibility

Every adopted effect requires:

- reduced-motion behavior
- keyboard/focus compatibility
- non-animated fallback

## Decision

**REFERENCE / SELECTIVE ADAPT**

Magic UI is a pattern library, not the TinyTots design language.
