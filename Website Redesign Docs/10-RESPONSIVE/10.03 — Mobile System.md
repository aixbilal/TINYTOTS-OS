# TinyTots Responsive System — Mobile

## Purpose

Define the primary small-screen experience.

## Principle

Mobile is a first-class composition, not a compressed desktop.

## Priorities

```text
CONTENT
>
PRODUCT DISCOVERY
>
PURCHASE
>
UTILITY
>
DECORATION
```

## Header

Prioritize:

- menu
- logo
- search
- cart

Exact arrangement follows Phase 07.

## Content

Use:

- strong hierarchy
- generous but efficient spacing
- readable line lengths
- minimal visual clutter

## Product Grid

Use card dimensions that preserve:

- image clarity
- product name readability
- price visibility
- touch usability

## Product Details

Recommended order:

```text
MEDIA
→
PRODUCT INFORMATION
→
VARIANTS
→
SIZE
→
PURCHASE
→
DETAILS
```

## Navigation

Use drawers, sheets, or drill-down patterns where appropriate.

## 3D

Default to the lightest experience that provides real value.

Heavy WebGL should not become a requirement for shopping.

## Definition of Done

A mobile customer can browse, search, view products, manage cart, and complete checkout without desktop-only interaction dependencies.
