# Categories Management

## Purpose

Maintain the catalog taxonomy used by customer discovery and administration.

## Core Operations

- create
- edit
- reorder where supported
- activate/deactivate where supported
- inspect product relationships

## Hierarchy

If nested categories exist, represent hierarchy clearly.

```text
Parent
├── Child
└── Child
```

## Impact Awareness

Before deleting or changing a category, show relevant dependencies where possible.

## SEO / URL

Category slugs and routes require collision and validity handling.

## Definition of Done

Administrators can safely modify taxonomy without accidentally orphaning products or routes.
