# Complaints Management

## Purpose

Provide a structured operational interface for customer complaints.

## Core Fields

Potentially:

- complaint reference
- customer
- order
- category
- description
- status
- priority
- assigned owner
- timestamps
- resolution

## Workflow

Actual workflow should be represented explicitly.

Example:

```text
NEW
→
IN REVIEW
→
ACTION REQUIRED
→
RESOLVED
```

Only use states supported by the system.

## Privacy

Restrict access according to role.

## Definition of Done

Staff can identify unresolved complaints and their required next actions quickly.
