# UGC Posts Management

## Purpose

Manage user-generated content that has appropriate publication rights.

## Core Operations

- review
- approve
- reject
- feature
- archive

## Rights

The UI should record or reference approval/permission status where the backend supports it.

## Media

Show previews without unnecessarily loading full-resolution assets.

## Definition of Done

Only authorized and approved UGC reaches public surfaces.
