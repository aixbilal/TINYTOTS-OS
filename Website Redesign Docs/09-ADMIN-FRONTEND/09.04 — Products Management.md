# Products Management

## Purpose

Manage the product catalog safely and efficiently.

## Core Operations

Depending on backend capabilities:

- list
- search
- filter
- create
- edit
- archive/delete where supported
- inventory/status management
- media management

## Product Table

Useful columns may include:

- image
- name
- SKU
- category
- price
- stock/status
- updated date
- actions

## Product Editor

Group fields logically:

```text
IDENTITY
PRICING
CATEGORY
VARIANTS
INVENTORY
MEDIA
DESCRIPTION
SEO / PUBLISHING
```

Exact fields must follow the actual schema.

## Validation

Validate required fields before submission and enforce business rules server-side.

## Unsaved Changes

Warn before leaving an editor with unsaved changes.

## Bulk Operations

Only provide actions that are safe and properly authorized.

## Definition of Done

An administrator can maintain products at realistic catalog scale without excessive navigation.
