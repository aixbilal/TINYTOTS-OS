# Discounts Management

## Purpose

Manage discount rules with explicit scope and validity.

## Potential Fields

- name
- type
- value
- eligible products/categories
- minimum conditions
- start/end dates
- status
- usage limits

Final fields must match backend capabilities.

## Validation

Prevent invalid combinations such as incompatible discount types or dates.

## Safety

Discount changes can have financial consequences.

Require appropriate authorization and confirmation for high-impact operations.

## Auditability

Where supported, retain:

- creator
- modifier
- timestamp
- status changes

## Definition of Done

Administrators can understand exactly what a discount does before activating it.
