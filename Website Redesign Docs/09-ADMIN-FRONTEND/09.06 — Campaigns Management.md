# Campaigns Management

## Purpose

Manage campaigns that may power the public website and digital signage.

## Campaign Areas

Potential controls:

- campaign identity
- status
- dates
- hero media
- focal point/crop
- featured products
- testimonials
- theme
- social links
- footer settings
- publishing state

Fields must follow the deployed schema.

## Preview

Provide a preview that reflects the actual presentation as closely as practical.

## Publishing

Distinguish:

```text
DRAFT
→
READY
→
PUBLISHED
```

if the backend supports such states.

## Source of Truth

Campaign configuration must not be duplicated unnecessarily between admin and frontend.

## Validation

Before publishing, check required assets and relationships.

## Definition of Done

An administrator can configure a campaign once and have supported consumer surfaces consume the same source of truth.
