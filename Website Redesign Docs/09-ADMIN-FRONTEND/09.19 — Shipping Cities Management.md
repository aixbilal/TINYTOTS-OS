# Shipping Cities Management

## Purpose

Manage the locations supported by shipping configuration.

## Core Operations

- add
- edit
- enable/disable
- search
- review shipping rules

## Data Integrity

Changes can affect checkout eligibility and pricing.

Show relevant dependencies before destructive changes.

## Naming

Use normalized location data consistent with backend rules.

## Definition of Done

Administrators can modify supported shipping locations without creating ambiguous checkout states.
