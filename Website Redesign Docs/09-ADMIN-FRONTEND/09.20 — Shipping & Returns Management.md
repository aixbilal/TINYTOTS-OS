# Shipping & Returns Management

## Purpose

Manage customer-facing shipping and return policy content where supported.

## Content

Potentially:

- shipping rules
- delivery information
- return eligibility
- return process
- refund information
- exceptions

## Policy Safety

Published policy should have a clear owner and update history where supported.

## Consistency

Customer-facing Help Center, Shipping & Returns page, and checkout messaging should not contradict each other.

## Definition of Done

Administrators can update policy information from a controlled source without creating conflicting copies.
