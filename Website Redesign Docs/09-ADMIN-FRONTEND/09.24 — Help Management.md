# Help Management

## Purpose

Manage customer-facing Help Center content where supported.

## Core Operations

- create
- edit
- categorize
- publish
- archive

## Article Structure

Use structured fields for:

- question/title
- answer
- category
- related content
- status

## Search

Content should remain searchable and consistently categorized.

## Definition of Done

Support content can be maintained without code changes and remains consistent with actual product policies.
