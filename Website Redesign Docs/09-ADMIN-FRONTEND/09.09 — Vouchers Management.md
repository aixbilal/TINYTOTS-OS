# Vouchers Management

## Purpose

Manage voucher-based customer incentives according to the actual business model.

## Requirements

The UI must clearly distinguish vouchers from:

- discounts
- coupons
- referrals

if these are separate backend concepts.

## Lifecycle

Potential states:

```text
CREATED
→
ACTIVE
→
USED / EXPIRED / REVOKED
```

Actual states must come from the backend.

## Financial Safety

Show enough information before issuance/revocation to prevent accidental value changes.

## Definition of Done

Administrators understand the voucher's value, eligibility, status, and lifecycle.
