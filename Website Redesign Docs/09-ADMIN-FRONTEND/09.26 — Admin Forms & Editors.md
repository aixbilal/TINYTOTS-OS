# Admin Forms & Editors

## Purpose

Create a consistent editing system across admin modules.

## Form Principles

- clear labels
- logical grouping
- sensible defaults
- inline validation
- explicit required fields
- preserved input on recoverable failure
- clear save state

## Save States

```text
UNCHANGED
→
DIRTY
→
SAVING
→
SAVED / ERROR
```

## Editors

Rich text/media editors should be constrained to supported content capabilities.

## Media

Show:

- preview
- upload state
- validation
- replacement
- removal

## Destructive Actions

Require confirmation appropriate to impact.

## Unsaved Changes

Warn when leaving a dirty form.

## Accessibility

All fields require:

- labels
- focus handling
- keyboard access
- useful validation messages

## Definition of Done

Forms behave consistently across all admin modules.
