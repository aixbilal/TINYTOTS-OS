# Testimonials Management

## Purpose

Manage testimonial records used across approved frontend surfaces.

## Potential Fields

- quote
- name/display name
- attribution
- image where supported
- status
- ordering

## Approval

Only approved content should be publishable.

## Privacy

Do not expose personal information beyond what the business has permission to publish.

## Definition of Done

Testimonials can be created, reviewed, ordered, and safely published.
