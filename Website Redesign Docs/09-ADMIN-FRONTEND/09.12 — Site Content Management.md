# Site Content Management

## Purpose

Centralize manageable global content.

## Potential Content

- announcement content
- navigation labels where supported
- footer content
- social links
- service messages
- reusable content blocks

## Source of Truth

Avoid maintaining the same value in multiple admin screens.

## Validation

Content editors should receive immediate feedback for:

- invalid URLs
- missing required fields
- unsupported formats

## Definition of Done

Global site content has a clear ownership location and does not drift across duplicated fields.
