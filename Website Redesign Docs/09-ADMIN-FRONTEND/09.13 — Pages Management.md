# Pages Management

## Purpose

Manage supported CMS-driven pages without turning the admin into an unrestricted code editor.

## Page Fields

Potentially:

- title
- slug
- status
- hero
- content blocks
- SEO metadata
- publication dates

## Editor

Use structured blocks where possible.

Avoid arbitrary HTML if it creates security or maintenance problems.

## Preview

Draft preview should be available where architecture supports it.

## Publishing

Show clear draft/published state.

## Definition of Done

Administrators can manage supported pages through safe structured content controls.
