# Admin Dashboard & Overview

## Purpose

The dashboard provides an operational snapshot, not a decorative analytics wall.

## Priority Information

Only display metrics that have reliable data sources.

Potential groups:

- orders
- revenue
- inventory
- customer activity
- campaigns
- complaints
- operational alerts

## Layout

```text
SUMMARY METRICS
↓
URGENT / ACTIONABLE ITEMS
↓
RECENT ACTIVITY
↓
PERFORMANCE / TRENDS
```

## Data Integrity

Every metric must have:

- defined source
- defined time range
- known calculation
- appropriate loading state

## Empty State

Explain why data is absent.

Do not fabricate sample numbers in production.

## Refresh

Where data is realtime or refreshed periodically, communicate freshness appropriately.

## Motion

Charts may animate on initial render, but animation must not delay access to values.

## Definition of Done

An administrator can identify important actions and current system state quickly.
