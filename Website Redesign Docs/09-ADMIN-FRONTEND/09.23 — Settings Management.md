# Settings Management

## Purpose

Centralize supported system/business settings.

## Categories

Potentially:

- store settings
- branding
- notifications
- integrations
- commerce settings
- system preferences

Only expose settings that actually exist.

## Safety

High-impact settings require:

- clear descriptions
- validation
- confirmation where appropriate

## Secrets

Secrets/API keys must not be unnecessarily rendered into the browser.

## Definition of Done

Every setting has a clear description, source, effect, and safe update mechanism.
