# Blog Management

## Purpose

Manage editorial articles.

## Core Operations

- create
- edit
- draft
- publish
- unpublish/archive
- categorize
- manage media

## Editor

Support:

- title
- slug
- excerpt
- body
- hero image
- metadata
- publication state

Exact fields follow schema.

## Preview

Editors should be able to review typography, imagery, and content hierarchy before publication.

## Definition of Done

Editorial staff can publish consistent articles without modifying frontend code.
