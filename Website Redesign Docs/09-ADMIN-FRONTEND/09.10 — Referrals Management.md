# Referrals Management

## Purpose

Manage and monitor the referral program if enabled.

## Potential Areas

- referral codes
- referrer
- referred customer
- reward
- status
- timestamps
- fraud/abuse indicators where supported

## Privacy

Only authorized administrators should access customer-related information.

## Status

Clearly distinguish pending, successful, rewarded, rejected, or other actual backend states.

## Definition of Done

Referral records can be reviewed without exposing unnecessary personal information.
