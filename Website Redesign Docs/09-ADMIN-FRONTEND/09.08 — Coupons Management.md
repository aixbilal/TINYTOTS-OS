# Coupons Management

## Purpose

Manage customer-facing coupon codes and their rules.

## Core Fields

Potentially:

- code
- discount rule
- validity
- usage limit
- customer eligibility
- status

## Code Handling

Normalize and validate codes according to backend rules.

Avoid ambiguous UI states around capitalization if the system treats codes case-insensitively.

## Security

Do not expose administrative secrets through client-side code.

## Actions

Use clear states:

- active
- scheduled
- expired
- disabled

## Definition of Done

Administrators can create and monitor coupons without ambiguity about their current behavior.
